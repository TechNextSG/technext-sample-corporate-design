common questions

Odoo pricing, answered.

How much does Odoo cost? {{icon:chevron}}

Odoo licences are priced per user per month by Odoo, with a free plan for a single app. Prices differ by country and currency, so check odoo.com/pricing for your market.

What does an Odoo implementation cost? {{icon:chevron}}

It depends on the scope: which apps, how many users, how much data to migrate, which integrations and custom modules, and how much training. TechNext quotes the implementation in writing once the scope is clear.

What is included in a TechNext quotation? {{icon:chevron}}

The implementation work for the scope you choose: configuration, data migration, training and integration, with support options for after go-live. The quotation states what is included and what is not.

Can we start small? {{icon:chevron}}

Yes. Most companies start with Accounting, Sales and Inventory, then add apps on the same database once the first phase is running.
