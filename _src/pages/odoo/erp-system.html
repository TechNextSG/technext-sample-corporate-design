Decision path

    Pick a requirement to start.

    Next version

      Odoo standard: a customer portal where customers download their orders and invoices is standard Odoo.

      Configuration: a purchase approval above S$5,000 is a Purchase setting; a trade price of 12% off from 50 units is a pricelist rule.

      Studio: a new field on the delivery slip and an invoice layout with your own columns are Studio work, with no code.

      Custom module on Odoo.sh: a tiered, split sales commission with clawback and a multi-level approval matrix with delegation need a separate, tested module.

      Integrations: a nightly sync with a legacy system is an integration, with mapping, scheduling and error handling.

      Each step up the stack adds upgrade risk, effort and maintenance, so the decision tree asks in order: does standard do it, can configuration, can Studio, and does it involve another system.

      common questions

      Odoo ERP, answered.

      What is an all-in-one ERP? {{icon:chevron}}

      One database where sales, stock, purchasing and accounting share the same records, instead of separate apps that don't talk to each other and have to be reconciled by hand.

      Do we need every module at once? {{icon:chevron}}

      No. Modules are switched on as you need them. Most companies start with Accounting, Sales and Inventory and add more as they grow.

      Where does Odoo run? {{icon:chevron}}

      Odoo Online for the fastest start on standard apps, Odoo.sh when you need custom development, or on-premise / your own cloud when data residency or existing infrastructure decides it. We help you choose.

      Will customisation break future upgrades? {{icon:chevron}}

      Not the way we build it. Customisations live in separate modules, are tested and documented, and never edit Odoo's own code — so the upgrade path stays predictable.

      Do the licences cost extra? {{icon:chevron}}

      Odoo licences are billed by Odoo per user per month. Our implementation and customisation work is quoted separately, so you can see each part clearly.

      How is it priced? {{icon:chevron}}

      On quotation, scoped to the apps, data and customisation you need — request a quotation.
