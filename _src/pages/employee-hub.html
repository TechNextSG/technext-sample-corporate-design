what's on an ID

Anatomy of a TechNext ID.

Every ID is built the same way, so a name, a position and an ID number can be read at a glance.

  1. TechNext bandThe blue header with the TechNext plane, as on every ID in the office.
  2. Photo slotThe person's photo, or their initials until one is added.
  3. Name and positionAs listed on this page.
  4. ID No.The person's number on the team list: No. 001, No. 002 and so on.
  5. Barcode stripThe strip along the bottom, read at the badge gate.
  6. Work emailWork details only, one tap to write.
  7. Our officesSingapore HQ, Taguig City and Ho Chi Minh City.
  8. Property line and VALID stampEvery ID belongs to TechNext Pte. Ltd.
